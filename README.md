# 🍽️ Restaurant Hub

A modern and responsive **Restaurant Hub** frontend website built using **HTML, CSS, and JavaScript**.

Restaurant Hub allows users to explore restaurants, filter restaurants by food category, search for restaurants or dishes, add items to a cart, and simulate the checkout process.
<p>
  Live - https://prince-kr-gupta.github.io/Resto-Hub/
</p>

## 🚀 Features

* 🏠 Modern landing page
* 🔍 Restaurant and food search
* 🍕 Food category filtering
* 🍔 Restaurant cards
* ⭐ Restaurant ratings
* ❤️ Favorite restaurant functionality
* 🛒 Add items to cart
* ➕ Cart item quantity tracking
* 💰 Automatic cart total calculation
* 🗑️ Remove items from cart
* 🎉 Frontend checkout simulation
* 🌙 Dark mode
* 💾 Dark mode preference saved using LocalStorage
* 📱 Fully responsive design
* 🎨 Clean and modern UI

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, animations, and responsive design
* **JavaScript** – Search, filtering, favorites, cart, checkout, and dark mode
* **LocalStorage** – Saving the user's theme preference

## 💻 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/prince-kr-gupta/Resto-Hub.git
```

### 2. Open the project

```bash
cd Resto Hub
```

### 3. Run the website

Open `index.html` directly in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.

## 🔎 Main Functionalities

### Search

Users can search for restaurants or food items using the search bar.

### Category Filter

Restaurants can be filtered by categories such as:

* 🍕 Pizza
* 🍔 Burgers
* 🍛 Indian
* 🥡 Chinese
* 🍰 Desserts

### Shopping Cart

Users can:

* Add food items
* View cart items
* Remove items
* See the total price
* Simulate checkout

### Dark Mode

The website includes a dark mode toggle, and the selected theme is saved using browser LocalStorage.
